Portfolio project

Project: scripting

Dit project is mijn eerste grote programmeerproject voor mijn studie. De opdracht bestond uit het bouwen van een website voor een fictief restaurant. De website bevat onder andere een homepage, een gerecht van de dag, een productmenu en een winkelmand.

HTML CSS JavaScript Responsive design

01

Overzicht van de website

Hier zie je verschillende pagina’s van de website. De afbeeldingen tonen het productmenu, de winkelmand, het gerecht van de dag en de volledige menupagina.

De website werd opgebouwd met een duidelijke navigatie en een overzichtelijke indeling. Klik op een afbeelding om deze te vergroten.

02

Demonstratievideo

In deze video laat ik zien hoe de website werkt. Ik demonstreer onder andere hoe producten aan de winkelmand worden toegevoegd en hoe een maximaal aantal per product wordt toegepast.

Daarnaast laat ik zien hoe de verschillende pagina’s werken en hoe de website tijdens het ontwikkelen werd getest.

03

Mijn bijdrage

Ik heb de structuur van de website gemaakt, de pagina’s vormgegeven en de interactieve onderdelen geprogrammeerd.

01

HTML-structuur

Ik heb de pagina’s opgebouwd met duidelijke en semantische HTML-elementen.

02

Vormgeving

Met CSS heb ik de layout, kleuren, afstanden en responsive weergave uitgewerkt.

03

Interactie

Met JavaScript heb ik interactieve onderdelen toegevoegd, zoals de winkelmand en het vergroten van afbeeldingen.
